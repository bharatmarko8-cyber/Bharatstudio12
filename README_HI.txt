Bharat Marko – Facts Studio (Android Studio Project)

यह Android ऐप प्रोजेक्ट है। इसे APK में बनाने के लिए:
1. Android Studio खोलें।
2. इस ZIP को Extract करें और Android Studio में BharatMarkoFacts फोल्डर खोलें।
3. Gradle Sync पूरा होने दें। Android SDK 35 इंस्टॉल होना चाहिए।
4. Build > Build Bundle(s) / APK(s) > Build APK(s) चुनें।
5. APK app/build/outputs/apk/debug/app-debug.apk में बनेगा।

ऐप में शामिल: YouTube Title, Description, Hashtags, Tags और Search Keywords जनरेटर।
यह प्रोजेक्ट स्थानीय HTML ऐप को Android WebView में चलाता है।
